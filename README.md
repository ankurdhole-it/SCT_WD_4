# SCT_WD_4 – Advanced To-Do Web Application

## 📌 Task Objective
Develop a modern and responsive To-Do Web Application that allows users to efficiently manage daily tasks with features like priorities, search, filtering, progress tracking, and persistent storage. :contentReference[oaicite:0]{index=0}

## ✨ Features
- Add tasks with due date, time, and priority
- Edit, delete, and mark tasks as completed
- Search tasks instantly
- Filter tasks (All, Active, Completed)
- Progress bar showing task completion percentage
- Task statistics (Total, Completed, Pending)
- Light/Dark mode with saved theme preference
- Local Storage support (tasks persist after refresh)
- Clear all completed tasks
- Responsive design for desktop and mobile devices :contentReference[oaicite:1]{index=1} :contentReference[oaicite:2]{index=2}

## 🛠️ Tech Stack

- JavaScript (Vanilla)
- Local Storage API
