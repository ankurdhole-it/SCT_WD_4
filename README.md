SCT_WD_4 – To-Do Web App
📌 Task Objective
Develop a to-do web application that allows users to add, organize, and manage tasks, with the ability to mark tasks as complete, edit them, and set a date & time for each task.
✨ Features

Add, edit, delete, and mark tasks as complete
Set due date, time, and priority (Low/Medium/High) for each task
Real-time search and filter (All/Active/Completed)
Live stats — total, completed, and pending task counts
Progress bar showing completion percentage
Dark mode toggle with saved theme preference
Data persistence using LocalStorage — tasks remain after page refresh
Responsive design for mobile and desktop

🛠️ Tech Stack

HTML5
CSS3
JavaScript (Vanilla)
Font Awesome & Google Fonts
